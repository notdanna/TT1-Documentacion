\subsubsection{Pruebas del sistema}

Las pruebas del sistema verificarán que cada funcionalidad del sistema
cumpla con los requerimientos funcionales definidos en la
sección~\ref{subsec:rf}, evaluando el comportamiento del sistema desde
la perspectiva del usuario final. Dado que el sistema se encuentra en
fase de diseño, esta sección presenta el plan de pruebas funcionales
que se ejecutará durante la fase de implementación del prototipo.

\textbf{Herramientas utilizadas:}

\begin{itemize}
    \item \textbf{Espresso:} Framework oficial de Google para pruebas
    de interfaz de usuario en Android. Se utilizará para verificar los
    flujos de navegación, la captura de imágenes, la visualización de
    resultados y el comportamiento offline de la aplicación móvil
    desarrollada con Kotlin y Jetpack Compose.
    \item \textbf{Postman + Newman:} Se utilizará para diseñar y
    ejecutar colecciones de pruebas sobre los endpoints REST expuestos
    por Amazon API Gateway. Newman permitirá automatizar la ejecución
    de estas pruebas desde el pipeline de GitHub Actions.
\end{itemize}
